# cryptotradinglearn

Сатирическая обучающая игра о криптотрейдинге **«НАЛОГ НА НАДЕЖДУ»** + лежащее в её основе
глубокое исследование рынка образовательных материалов по криптотрейдингу (140 источников, 5 итераций).

## Структура

```
deep-research-instructions/   инструкции исследования (iter1–iter5)
style-tone.txt                стиль текстов игры: панк-таблоидная криптосатира
research/                     выполненное исследование
  iteration-1/                карта рынка, 21 сегмент, реестр SRC-0001…0112
  iteration-2/                содержание: 74 TERM-ID, 27 METHOD-ID, риск-матрица
  iteration-3/                критический аудит: 30 claims, 10 конфликтов, 18 пробелов
  iteration-4/                аудит полноты: C0–C7, FINAL_RESEARCH_CORPUS
  iteration-5/                синтез: учебная система 0–99, допуск A–F
game/                         играбельный прототип: главы 1–2 «Приёмная» + «Биржа и исполнение» (уровни 0–20)
  index.html · style.css · content.js · engine.js · DESIGN.md · test/
```

## Запуск игры

Открыть `game/index.html` в браузере — или:

```
cd game && python3 -m http.server 8000
```

Headless-тест всей главы: `cd game && npm i jsdom && node test/smoke.test.js`

## Принципы

- Не обещать доходность — единственное обещание, которое на этом рынке выполняется.
- Каждый факт в игре — из исследования (SRC-ID в «Справках из архива»), каждая шутка — про механику.
- Сатира — обёртка. Факты — начинка.
