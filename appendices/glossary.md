# Приложение · Глоссарий трейдера без лишнего жаргона

Термин сначала объясняется простыми словами, затем — в рабочем значении. Если незнакомое слово встречается в уроке, сверяйтесь с этим глоссарием, а не пытайтесь угадывать по графику.

[[[Таблица / plain language cryptocurrency trading glossary ]]]]

| Термин | Простое объяснение | Рабочее значение в курсе |
|---|---|---|
| Актив | То, чем торгуют. | Монета, токен или контракт. |
| Ask | Цена, по которой сейчас готовы продать. | Самый низкий ask — лучший ask. |
| ATR | Обычная ширина движения цены. | Средний истинный диапазон; линейка стопа, не направление. |
| Base asset | Первый актив в паре. | В `ETH/USDT` это ETH. |
| Bid | Цена, по которой сейчас готовы купить. | Самый высокий bid — лучший bid. |
| Breakout | Выход цены за важную зону. | Торгуется только с правилами принятия/отмены. |
| Bracket | Связка входа, стопа и цели. | Упрощает исполнение плана; не гарантирует fill. |
| Candlestick | Свеча за период. | Показывает open, high, low, close. |
| Cap | Размер оценки токена рынком. | Market cap = цена × circulating supply. |
| Circulating supply | Токены, доступные рынку. | Не равен максимальной эмиссии. |
| Close | Цена закрытия свечи. | Не равна гарантированной цене исполнения. |
| Корреляция | Склонность активов двигаться вместе. | В стресс повышается; риск считают по кластеру. |
| Drawdown | Снижение счёта от прошлого максимума. | Отслеживается в R и процентах. |
| Edge | Повторяемое преимущество. | Положительное net expectancy в заданном режиме. |
| EMA | Быстрая скользящая средняя. | Сильнее учитывает последние цены. |
| Expectancy | Средний ожидаемый итог сделки. | Считается в net R по выборке, а не «на глаз». |
| FDV | Оценка при полном предложении токенов. | Цена × максимальный/плановый supply. |
| Fill | Фактическое исполнение заявки. | Для журнала важнее желаемой цены. |
| Funding | Периодический платёж в perpetual-контракте. | Расход/доход позиции и индикатор перекоса, не прогноз. |
| Higher low (HL) | Минимум выше прошлого важного минимума. | Часть восходящей структуры. |
| Higher high (HH) | Максимум выше прошлого важного максимума. | Часть восходящей структуры. |
| Invalidation | Момент, когда идея перестала быть верной. | Основа для стопа, определяется до входа. |
| Ликвидность | Возможность купить/продать без сильного сдвига цены. | Оценивается глубиной, спредом и объёмом. |
| Ликвидация | Принудительное закрытие маржинальной позиции. | Авария; не заменяет стоп. |
| Limit-ордер | Заявка по заданной цене или лучше. | Защищает цену, но может не исполниться. |
| Long | Ставка на рост купленного актива. | Прибыль при росте, убыток при падении. |
| Lower high (LH) | Максимум ниже прошлого важного максимума. | Часть нисходящей структуры. |
| Lower low (LL) | Минимум ниже прошлого важного минимума. | Часть нисходящей структуры. |
| Maker | Тот, кто добавил ликвидность в книгу. | Может платить другую комиссию. |
| Market-ордер | Заявка на немедленное исполнение. | Получает доступную цену, а не гарантированную. |
| Market cap | Оценка обращающихся токенов рынком. | Цена × circulating supply. |
| Mean reversion | Возврат цены к среднему. | Семейство для диапазона, не для сильного тренда. |
| OCO | Два взаимоисключающих выхода. | Исполнение одного должно отменить другой. |
| OHLC | Четыре цены свечи. | Open, high, low, close. |
| OI | Открытый интерес в деривативах. | Количество открытых контрактов/номинала по методике площадки. |
| Order book | Список ожидающих заявок. | Снимок намерений, не гарантия ликвидности. |
| Paper trading | Учебная торговля без реальных денег. | Исполняется по реальным правилам и издержкам. |
| Position size | Размер позиции. | Следствие риска и стоп-дистанции. |
| Pullback | Откат внутри движения. | Не равен развороту без слома структуры. |
| R | Единица планового риска. | Стоп = примерно −1R; выход +2R = две единицы риска. |
| R:R | Соотношение прибыли к риску. | Плановая геометрия; сравнивается с реализованным avg win. |
| Range | Боковой коридор цены. | Имеет границы, середину и риск выхода. |
| Retest | Повторная проверка уровня после пробоя. | Возможный триггер, но не обязан произойти. |
| Risk of Ruin | Риск критически повредить капитал. | Зависит от edge, размера риска, серий и корреляций. |
| Slippage | Разница между ожидаемой и фактической ценой. | Особенно важна в тонком рынке и стресс. |
| SMA | Простая скользящая средняя. | Равный вес прошлым ценам в периоде. |
| Спред | Разница лучшего bid и ask. | Невидимая издержка входа/выхода. |
| Стоп-лосс | Заявка/правило закрыть ошибочную идею. | Ставится по структуре, не по размеру боли. |
| Структура рынка | Последовательность экстремумов. | HH/HL или LH/LL на выбранном ТФ. |
| Taker | Тот, кто забрал ликвидность из книги. | Обычно исполняется немедленно и платит свою комиссию. |
| Таймфрейм | Длина одной свечи. | Масштаб наблюдения, не скорость рынка. |
| Тейк-профит | Плановая фиксация прибыли. | Не отменяет необходимость следить за исполнением. |
| Token unlock | Выход ранее заблокированных токенов. | Событие риска предложения, не автоматический сигнал. |
| TVL | Стоимость активов, заблокированных в протоколе. | Прокси масштаба, требующий проверки методики. |
| Volatility | Амплитуда колебаний. | Определяет стоп-дистанцию и размер. |
| Walk-forward | Проверка правил на следующем участке данных. | Параметры не меняют между train и test. |
| Win-rate | Доля прибыльных сделок. | Нельзя оценивать отдельно от среднего win/loss и costs. |

## Три вопроса к любому новому термину

1. **Что он измеряет?** Например, ATR измеряет диапазон, не направление.
2. **Чего он не измеряет?** Funding не предсказывает следующую свечу.
3. **Какое решение он может изменить?** Например, высокий funding может уменьшить размер или запретить удержание через выходные.
