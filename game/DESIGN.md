# НАЛОГ НА НАДЕЖДУ — дизайн-документ

Сатирическая обучающая игра о криптотрейдинге. Уровни 0–99, 8 глав.
Основа: исследование рынка образовательных материалов по криптотрейдингу (`research/`, 140 источников, 5 итераций).
Стиль текстов: `style-tone.txt` — панк-таблоидная криптосатира.

## 1. Концепция

Рынок описывается как абсурдная цивилизация: киты, стадо, регуляторы (всегда «обеспокоены»), служба по
перераспределению чужих денег, департамент управляемой паники. Игрок — не герой, а участник системы,
который «здесь ради денег, и именно поэтому уже в опасности».

Двойной слой подачи:
- **сатира** — обёртка (заголовки, исходы выборов, бегущая строка, псевдоофициальные термины);
- **«Справка из архива»** — начинка: в конце каждого уровня нейтральная карточка с фактом из исследования
  и ссылками SRC/TERM/METHOD/CL-ID. Шутка раскрывает механику, справка её подтверждает.

## 2. Соответствие учебной системе (research/iteration-5)

| Глава | Уровни | Макроблок | Статус в прототипе |
|---|---|---|---|
| 1. Приёмная | 0–10 | основы и безопасность | ✅ играбельна (11 уровней) |
| 2. Биржа и исполнение | 11–20 | ордера, комиссии, маржа, ликвидация, фандинг | каркас на карте |
| 3. Анализ рынков | 21–35 | TA/SMC/on-chain/FA с паспортом доказательности | каркас |
| 4. Классы подходов | 36–50 | каталог классов + выбор | каркас |
| 5. Систематика | 51–65 | формализация, код, бэктест | каркас |
| 6. Валидация | 66–80 | метрики, искажения, walk-forward, Monte Carlo | каркас |
| 7. Профметоды | 81–90 | опционы, фандинг, исполнение, налоги | каркас |
| 8. Исследователь | 91–99 | чтение/репликация работ, доктрина | каркас |

Ключевые решения главы 1 (взяты из исследования, а не выдуманы):
- статистика потерь (Бразилия 97%, Тайвань <1%, ESMA 74–89%) — обязательный уровень 8–9 с «подписью» —
  потому что ни один из 140 образовательных источников не сообщает её ученикам до первой сделки;
- «налог на надежду» (штрафы за ошибки безопасности) — ошибки стоят денег до первой сделки;
- «индекс веры в график» — инвертированный прогресс: чем ниже вера, тем лучше калибровка;
- спрятать нельзя пропустить: кнопка «ПРОПУСТИТЬ» уволится.

## 3. Механики прототипа (глава 1)

- `text` — подача сцен;
- `choice` — выбор с исходом и эффектами (капитал/вера);
- `urls` — раунды «какой домен настоящий» (антифишинг);
- `flags` — мини-игра «найди красные флаги» (материал SEC/CFTC + GAP-08);
- `report` — «отчёт, который никто не читает» с увольняющейся кнопкой пропуска;
- `sign` — подпись под статистикой потерь (три варианта, надежда не меняет статистику);
- `exam` — экзамен уровня 10 (порог 4/5 = 80%, пересдача бесконечна: «рынок подобных скидок не делает»).

HUD: уровень N/99, демо-капитал, индекс веры в график, статус («клиент приёмной» → «выживший 0–10»).
Прогресс сохраняется в localStorage. Аттестат главы содержит «уплаченный налог на надежду».

## 4. Правила честности (перенесены из итерации 5, §13)

1. Не обещать доходность — ни в одном тексте (единственное обещание игры: обещаний не будет).
2. Каждый факт — из исследования, с SRC-ID в «Справке из архива».
3. Сатирические формулировки не подменяют факты: шутка — обёртка, справка — начинка.
4. Не выдавать сатиру за финансовую рекомендацию (дисклеймер на титуле и в футере).
5. Пересдачи разрешены (образование), критерий прохождения — знания, не «прибыль».

## 5. Замысел глав 2–8 (для продолжения)

- **Гл. 2:** симулятор исполнения: maker/taker, slippage, цена ликвидации, фандинг; демо «идеальных
  исполнений» показывается и разрушается (CF-02). Босс главы — первый реальный расчёт ликвидации.
- **Гл. 3:** чтение графиков, где каждый инструмент подписан своим доказательным статусом
  (по лестнице доказательности: от peer-reviewed до «не подтверждено»).
- **Гл. 4:** «выбери способ потерять деньги» — каталог классов с издержками и риск-профилем.
- **Гл. 5:** сборка правила из гипотезы (вход/выход/размер) без дискреции; мини-бэктест.
- **Гл. 6:** «твой бэктест врёт» — 40 уроков о data snooping, OOS, Monte Carlo; поиск 10 искажений.
- **Гл. 7:** опционы/фандинг/исполнение; сквозная задача «спроектировать операцию».
- **Гл. 8:** репликация чужого исследования; финальный босс — собственная доктрина с границами незнания.

## 6. Файлы и запуск

```
game/
  index.html   — разметка (мастхед, HUD, экран, бегущая строка)
  style.css    — панк-таблоидная вёрстка (тёмная газета)
  content.js   — весь текстовый контент (уровни, тикер, главы, аттестат)
  engine.js    — движок сцен (vanilla JS, без зависимостей)
  test/smoke.test.js — headless-прогон всей главы (jsdom)
```

Запуск: открыть `game/index.html` в браузере или `python3 -m http.server` в каталоге `game/`.
Тест: `cd game && npm i jsdom && node test/smoke.test.js`.
